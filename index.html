เกี่ยวกับฉัน

สวัสดีค่ะ ฉันชื่อ ปัทมา ชาลีกุล มีความสนใจด้านการออกแบบเว็บไซต์ การพัฒนาเว็บไซต์ และการออกแบบสื่อดิจิทัล ชอบเรียนรู้เทคโนโลยีใหม่ ๆ และนำความคิดสร้างสรรค์มาประยุกต์ใช้ในการสร้างผลงาน

นักออกแบบเว็บไซต์และนักพัฒนาเว็บไซต์

ฉันสนใจการออกแบบเว็บไซต์ที่มีความสวยงาม ใช้งานง่าย และสามารถตอบโจทย์ผู้ใช้งาน พร้อมทั้งสนใจการพัฒนาเว็บไซต์ด้วย HTML, CSS และ JavaScript
